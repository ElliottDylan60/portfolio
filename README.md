# Welcome

Welome to my page! Here you will find my portfolio built in laravel and a postgreSQL database to store my projects. A lot of my github projects are private or more DevOps focused and I wanted to create a space to share my work.

## About the project

I wanted to create something a little different from a traditional portfolio website. Inspired by Proxmox Virtual Environment, this portfolio is designed to resemble an infrastructure management dashboard. Each container represents a different aspect of my professional experience, technical skills, and personal projects. Feel free to explore the environment, interact with the different systems, and learn more about the technologies I've worked with!
